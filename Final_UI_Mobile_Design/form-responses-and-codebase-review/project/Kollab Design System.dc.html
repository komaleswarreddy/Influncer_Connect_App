house rules
Every button, tag, tab and segmented control is 999px. There is no other button radius.
Headlines are left-aligned over asymmetric card grids. Nothing is centred by default.
One italic serif emphasis word per heading. Two reads as decoration.
Text over a photo always sits on a scrim — never on the raw image.
No hex value or font name inside a screen file. Import from the token file.
No emoji as icons or section markers. No dark theme.
